# жуж: Runic Programming with Polari-Esperanto 

Welcome to жуж!
Where ancient vibes meet modern code in a dance of runes and Roman numerals.

## What is жуж?
жуж is a simple interpreter that combines runic script with Roman numerals for a unique programming experience.

## How Does It Work?

### Syntax
- Variables are written in Elder Futhark runes
- Numbers are written in Roman numerals
- Variable declarations use ᚹᚨᛞᚨ (wada)

### Examples
Variable Declaration:
```javascript
ᚹᚨᛞᚨ ᛟᛗᛁ = XLII;  // Creates variable ᛟᛗᛁ with value 42
```

### Features
- Direct runic variable naming
- Roman numeral support
- Basic error handling with "Naff funkcio" messages

## Usage
Include zhuzh.js in your HTML:
```html
<script src="zhuzh.js"></script>
```

Write your жуж code:
```javascript
ᚹᚨᛞᚨ ᛟᛗᛁ = XLII;
```
